💜 UniVibe – Your Student Social Network

UniVibe is a student-focused social networking platform designed to help students connect, share ideas, discover communities, and grow together.

✨ Features

- Student Registration and Login
- Secure password hashing
- MongoDB database integration
- Create and view posts
- Comment on posts
- Save posts
- Follow and unfollow students
- Explore community posts
- Notifications
- Responsive mobile-friendly design
- Student dashboard
- Logout functionality

🛠️ Technologies Used

Frontend

- HTML5
- CSS3
- JavaScript

Backend

- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- JSON Web Token (JWT)
- bcryptjs

🚀 Getting Started

1. Clone the Repository

git clone YOUR_GITHUB_REPOSITORY_URL

2. Open the Project

cd UNIVIBE

3. Install Dependencies

npm install

4. Configure Environment Variables

Create a ".env" file with your own MongoDB connection string, port, and JWT secret.

Never share your database credentials or upload ".env" to GitHub.

5. Start the Backend

node server.js

6. Open the Frontend

Open "index.html" using VS Code Live Server.

🗄️ Database

UniVibe uses MongoDB Atlas to store student account information and posts.

The application supports desktop, tablet, and mobile screen layouts.
